Weather-Dashboard-Updater

Gathers data about the weather from the OpenWeatherMap API. One small Python script, get_weather_data.py, takes the reading and writes it down: every run appends one structured row to weatherupdate.csv, the record a dashboard reads.

How to run this script

Go sign up for openweathermap to obtain an API key
git clone https://github.com/Epsilon0xCell/Weather-Dashboard-Updater.git
rm -rf weatherupdate.csv # Remove the existing .csv as this includes previous data.
pip install requests pandas
python3 get_weather_data.py

Get a key at home.openweathermap.org/api_keys. The script reads the key from the API_KEY environment variable, and the place and country are set in the script itself: Milwaukee, US. The README's run block shows a redacted placeholder where your own key goes; leave the placeholder exactly as written there and keep your real key in the environment. The file is output to a .csv in the current working directory, letting you view the weather data in .csv format.

What a run does

AskThe script builds the OpenWeatherMap current weather URL for its set city and country and sends the request.
FlattenThe JSON answer is flattened into one row: nested groups become single columns named for where they came from.
ValidateIf weatherupdate.csv already exists, validate_csv_structure checks it first and removes rows whose field count disagrees with the header.
AppendThe new row is appended (the header is written only when the file is new), and the file is read back and rewritten through pandas for consistent formatting.

The record: 27 columns

The CSV file contains the following columns, well-organized and formatted for easy readability:

coord_loncoord_latweather_idweather_mainweather_descriptionweather_iconbasemain_tempmain_feels_likemain_temp_minmain_temp_maxmain_pressuremain_humidityvisibilitywind_speedwind_degclouds_alldtsys_typesys_idsys_countrysys_sunrisesys_sunsettimezoneidnamecod

Temperatures carry the API units (default Kelvin, metric Celsius, imperial Fahrenheit), pressure is hPa, humidity and cloudiness are percents, visibility is metres, and the times are unix UTC. The committed weatherupdate.csv in the repo is the accumulated output of past runs, about 7.3 MB of readings; the run instructions remove it first only when you want a fresh record.

The files

get_weather_data.py, the whole script. weatherupdate.csv, the accumulated output data. requirements.txt, the two packages (requests and pandas). LICENSE, GPL-3.0. Column by column notes are in the repo README.

The station reads the sky once per run and files the reading; the record is the whole point.
